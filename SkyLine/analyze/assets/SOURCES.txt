Moon color texture: NASA Scientific Visualization Studio, CGI Moon Kit, ID 4720.
https://svs.gsfc.nasa.gov/4720/
Downloaded 24 October 2026: lroc_color_2k.jpg (2048 x 1024).
Visualization by Ernie Wright. Source imagery from LRO instrument teams.
This texture is optimized for aesthetics, not science. No terrain, lighting, or ephemeris analysis uses it.

Moon relief: NASA Scientific Visualization Studio CGI Moon Kit, ID 4720.
https://svs.gsfc.nasa.gov/4720/
Derived from ldem_16_uint.tif (LOLA global elevation, 16 pixels per degree), resampled and converted to 8-bit for visual bump shading. Relief is exaggerated and does not provide terrain-aware calculations. Credit: NASA Scientific Visualization Studio / Ernie Wright.

Moon 4K color: NASA Scientific Visualization Studio CGI Moon Kit, ID 4720.
https://svs.gsfc.nasa.gov/4720/
Derived from lroc_color_16bit_srgb_4k.tif, converted to WebP for display. Credit: NASA Scientific Visualization Studio / Ernie Wright.
